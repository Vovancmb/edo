# ЭДО — электронный документооборот с ЭП

Внутренний сервис для загрузки, подписания и согласования документов.
Поддерживает категории, разграничение доступа и электронную подпись.

## Стек
- Node.js 20 (ESM) + Express 4
- SQLite (better-sqlite3)
- JWT + bcryptjs
- pdf-lib, multer, fontkit

## Запуск
1. Скопируйте `.env.example` в `.env` и заполните.
2. `docker compose up -d --build`
3. Приложение доступно на `http://localhost:3000`.

## Переменные окружения
См. `.env.example`.
